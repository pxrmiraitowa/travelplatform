# 旅游平台项目用户文档

## 1. 项目简介

本项目是一个综合旅游平台示例系统，包含前台用户端和后台管理端两部分，覆盖以下典型业务：

- 用户注册、登录、退出
- 机票查询、详情查看、下单
- 火车票查询、详情查看、下单
- 酒店查询、详情查看、预订
- 旅游度假产品浏览、详情查看、下单
- 统一订单中心
- 行程规划
- 旅行分享发布与浏览
- 订单评价
- 价格对比与价格提醒
- 后台用户、商品、订单、内容管理

项目技术栈：

- 前端：Vue 3、Vite、Vue Router、Pinia、Element Plus、Axios
- 后端：Spring Boot 3、Spring Security、MyBatis-Plus、MySQL、JWT

## 2. 系统角色

系统包含两类主要角色：

- 普通用户：注册登录后可使用前台业务功能
- 管理员：登录后台后可管理用户、产品、订单、分享和评价内容

## 3. 运行环境与启动方式

### 3.1 环境要求

- JDK 17
- Maven 3.9+
- MySQL 8.x
- Node.js 18+ 或兼容版本

### 3.2 后端启动

后端目录：

```text
travel-platform-server
```

默认配置来自 `travel-platform-server/src/main/resources/application.yml`：

- 服务端口：`8080`
- 数据库：`travel_platform`
- 数据库账号：`root`
- 数据库密码：`123456`
- Swagger 地址：`http://localhost:8080/swagger-ui.html`

启动方式：

```bash
cd travel-platform-server
mvn spring-boot:run
```

说明：

- 项目启动时会自动执行 `schema.sql`
- 会自动建表并插入一批演示数据
- 图片上传目录默认是后端目录下的 `uploads`

### 3.3 前端启动

前端目录：

```text
travel-platform-web
```

启动方式：

```bash
cd travel-platform-web
npm install
npm run dev
```

默认访问地址：

- 前端页面：`http://localhost:5173`

前端已配置代理：

- `/api` 会代理到 `http://localhost:8080`

## 5. 前台功能使用说明

### 5.1 首页

首页用于展示平台主要业务入口，用户可从这里进入：

- 机票
- 火车票
- 酒店
- 旅游度假
- 旅行分享
- 行程规划
- 我的订单

### 5.2 注册与登录

访问路径：

- 用户登录/注册：`/login`

支持：

- 新用户注册
- 已有用户登录
- 登录后自动保存登录状态到浏览器本地存储

### 5.3 个人中心

访问路径：

- `/profile`

个人中心支持以下能力：

- 查看当前账号基础信息
- 修改昵称、真实姓名、手机号、邮箱、性别
- 管理常用出行人
- 查看并删除价格提醒

常用出行人字段包括：

- 姓名
- 联系电话
- 身份证号
- 类型
- 是否默认
- 备注

说明：

- 机票、火车票、酒店、旅游下单时都会依赖常用出行人
- 如果没有常用出行人，部分下单页面会提示先去个人中心维护

### 5.4 机票模块

访问路径：

- 列表页：`/flight`
- 详情页：`/flight/{id}`
- 下单页：`/flight/{id}/booking`

支持功能：

- 按条件搜索航班
- 查看航班详情
- 查看价格对比信息
- 创建价格提醒
- 选择常用出行人提交订单
- 自动推荐符合门槛的优惠券

说明：

- 创建价格提醒需要先登录
- 提交订单后会生成订单记录，并进入订单中心

### 5.5 火车票模块

访问路径：

- 列表页：`/train`
- 详情页：`/train/{id}`
- 下单页：`/train/{id}/booking`

支持功能：

- 查询车次
- 查看车次详情
- 选择座位类型
- 选择常用出行人下单

### 5.6 酒店模块

访问路径：

- 列表页：`/hotel`
- 详情页：`/hotel/{id}`
- 预订页：`/hotel/{id}/booking`

支持功能：

- 按城市等条件搜索酒店
- 查看酒店信息与房型列表
- 查看价格对比信息
- 创建价格提醒
- 选择入住日期、离店日期、入住人和优惠券提交订单

说明：

- 酒店价格会根据入住晚数计算总金额
- 下单页会根据订单金额自动匹配可用优惠券

### 5.7 旅游度假模块

访问路径：

- 列表页：`/tour`
- 详情页：`/tour/{id}`
- 下单页：`/tour/{id}/booking`

支持功能：

- 浏览度假产品
- 查看产品详情
- 查看价格对比信息
- 创建价格提醒
- 选择出行人和出发日期提交订单

### 5.8 统一订单中心

访问路径：

- 订单列表：`/orders`
- 订单详情：`/orders/{id}`

支持功能：

- 统一查看机票、火车票、酒店、旅游订单
- 按业务类型筛选订单
- 按订单状态筛选订单
- 查看订单明细
- 取消订单
- 对已完成订单发起评价

当前订单状态定义：

- `10`：待支付
- `20`：待出行
- `30`：已完成
- `40`：已取消

说明：

- 本项目不接入真实支付
- 提交订单后通常先进入“待支付”状态
- 订单状态可由后台进行更新，便于演示完整业务流

### 5.9 行程规划

访问路径：

- 列表页：`/trip-plans`
- 详情页：`/trip-plans/{id}`

支持功能：

- 创建行程计划
- 编辑行程计划
- 删除行程计划
- 查看行程详情
- 维护每日行程安排

适用场景：

- 自由行行程整理
- 多日出游安排记录
- 演示从“计划”到“预订”的平台能力扩展

### 5.10 旅行分享

访问路径：

- 分享列表：`/shares`
- 发布分享：`/shares/create`
- 分享详情：`/shares/{id}`

支持功能：

- 浏览公开分享
- 登录后发布分享
- 上传图片
- 填写标题、摘要和正文

说明：

- 分享图片会上传到后端本地目录
- 后台支持对分享内容进行管理

### 5.11 订单评价

评价入口主要出现在订单中心。

支持功能：

- 对已完成且尚未评价的订单进行评价
- 填写星级评分
- 填写评价内容

说明：

- 一个订单只能评价一次
- 后台支持对评价内容进行查看和删除

### 5.12 价格对比与价格提醒

价格对比能力覆盖：

- 机票详情页
- 酒店详情页
- 旅游产品详情页

价格提醒支持：

- 登录后创建提醒
- 在个人中心查看提醒列表
- 删除已有提醒

说明：

- 价格提醒属于演示型业务能力
- 价格变化状态由当前数据库中的价格信息计算，不涉及外部实时第三方接口

## 6. 后台管理功能使用说明

### 6.1 后台登录

访问路径：

- `/admin/login`

管理员登录成功后进入后台控制台：

- `/admin/dashboard`

### 6.2 控制台

后台控制台可查看系统概览信息，用于快速了解：

- 用户数量
- 商品数量
- 订单数据
- 内容数据

### 6.3 用户管理

访问路径：

- `/admin/users`

支持功能：

- 查看用户列表
- 查看用户详情
- 修改用户状态
- 修改用户角色

### 6.4 商品管理

后台商品管理覆盖以下模块：

- 航班管理：`/admin/products/flights`
- 车次管理：`/admin/products/trains`
- 酒店管理：`/admin/products/hotels`
- 房型管理：`/admin/products/rooms`
- 旅游产品管理：`/admin/products/tours`

每个模块通常支持：

- 列表查询
- 新增
- 编辑
- 删除

### 6.5 订单管理

访问路径：

- 订单列表：`/admin/orders`
- 订单详情：`/admin/orders/{id}`

支持功能：

- 按关键字筛选订单
- 按业务类型筛选订单
- 按状态筛选订单
- 查看订单详情
- 修改订单状态
- 后台取消订单

适合演示的典型流程：

1. 用户提交订单
2. 后台查看订单
3. 管理员将订单状态改为“待出行”或“已完成”
4. 用户在前台查看订单变化并进行评价

### 6.6 内容管理

后台内容管理包括：

- 分享管理：`/admin/content/shares`
- 评价管理：`/admin/content/reviews`

支持功能：

- 查看内容列表
- 删除不合适内容

## 7. 初始化演示数据说明

- 航班数据

- 使用默认账号登录

- 创建订单
- 查看订单中心
- 发布分享
- 使用后台查看和管理业务数据

## 9. 使用建议

为了更顺畅地演示项目，建议按以下顺序体验：

1. 启动 MySQL、后端、前端
2. 用普通用户登录前台
3. 在个人中心先维护常用出行人
4. 体验机票、酒店或旅游产品下单
5. 在订单中心查看订单记录
6. 使用管理员账号登录后台
7. 在后台修改订单状态
8. 返回前台查看订单状态变化并完成评价
9. 体验分享发布与后台内容管理

## 10. 注意事项

- 本项目为本地演示型系统，不接入真实支付
- 价格提醒和价格对比为站内演示能力，不依赖第三方实时数据源
- 分享图片上传到本地目录，部署时需注意文件存储和访问策略
- 前端登录页和后台登录页目前都不会自动填充默认账号密码
- 若修改了数据库连接信息，需要同步更新 `application.yml`
