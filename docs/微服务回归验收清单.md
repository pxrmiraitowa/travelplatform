# 微服务回归验收清单

## 1. 验收目标

本文用于记录微服务版本在课程验收前需要覆盖的 API 回归和业务场景回归。验收入口统一以 gateway `http://localhost:8000` 为准，前端本地调试通过 Vite 代理访问 `/api`。

## 2. 自动化命令

| 类型 | 命令 | 预期 |
| --- | --- | --- |
| 后端编译 | `mvn -pl user-service,product-service,order-service,content-trip-service,gateway-service -am compile` | 六个模块编译通过 |
| 订单单测 | `mvn -pl order-service -am test` | 订单服务规则测试通过 |
| 前端构建 | `npm run build` | Vite 生产构建通过 |
| 前端单测 | `npm run test:unit` | Vitest 用例通过 |
| gateway 烟测 | `powershell -ExecutionPolicy Bypass -File .\scripts\smoke-gateway.ps1` | 公开接口、登录、后台鉴权、后台路由通过 |

## 4. 当前已知约束

预订页暂时隐藏优惠券选择，订单金额由 order-service 按 product-service 商品快照计算。完整优惠券链路后续需要在 order-service 增加 `couponId` 校验和优惠金额计算。

后台订单详情在微服务版本中使用订单快照展示产品摘要，不再跨服务读取产品表；这是符合服务边界的演示级实现。后台内容管理查询用户和订单展示信息时允许降级，避免 user-service 或 order-service 短暂不可用时影响内容列表打开。

真实端到端回归需要本机 MySQL 中存在对应的 `travel_user`、`travel_product`、`travel_order`、`travel_content_trip` 数据库和演示数据。执行 smoke 脚本前需要先启动四个业务服务和 gateway。
