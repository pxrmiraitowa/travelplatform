# 公开接口自动化测试覆盖矩阵

## 1. 执行方式

GitHub Actions 在五个服务构建、单元测试、镜像制作和 Kind 部署完成后，通过网关执行：

```bash
cd travel-platform-web
npm run test:regression
```

测试失败会阻止部署任务成功，并上传 `deployed-regression.log`、服务日志、Pod 状态和事件记录。测试数据使用随机后缀并在用例结束时清理，可重复执行。

## 2. 业务场景

| 用例 | 覆盖场景 | 关键断言 |
| --- | --- | --- |
| UC01 | 注册、登录、当前用户 | JWT 和当前用户名正确 |
| UC02 | 修改资料、联系人增删改查 | 所有者数据可见且修改生效 |
| UC03 | 航班、优惠券下单、取消 | 库存下单减 1，取消恢复 |
| UC04 | 车次席别下单、支付、退款 | 状态流转及退款恢复库存 |
| UC05 | 酒店房型预订、取消 | 规格快照和取消成功 |
| UC06 | 旅游产品下单、取消 | 商品类型和状态正确 |
| UC07 | 订单列表、详情、取消 | 订单归属和查询完整 |
| UC08 | 完成订单、评价 | 可评价列表、评价创建和查询 |
| UC09 | 行程及行程项增删改查 | 行程详情和每日安排一致 |
| UC10 | 智能行程预览与保存 | 通过产品服务取得景点候选并保存 |
| UC11 | 分享发布、我的分享、公开详情、删除 | 内容归属和公开读取正确 |
| UC12 | 价格比较、价格提醒 | 商品快照和提醒增删查正确 |
| UC13 | 五类后台商品资源增删改查 | 航班、车次、酒店、房型、旅游产品均覆盖 |
| UC14 | 后台仪表盘、用户、订单、分享和评价 | 列表、详情、状态与删除接口均覆盖 |

## 3. 通用接口

`public-api.test.js` 额外覆盖五个后端进程的健康检查和版本号，以及航班、车次、酒店、旅游产品、价格比较、公开分享和认证边界。流水线还单独执行前端 Vitest 单元测试和 Maven 单元测试；五个服务模块都至少包含一个独立测试类。

健康检查只表示进程可用，端到端回归才作为业务可部署的最终门禁。
