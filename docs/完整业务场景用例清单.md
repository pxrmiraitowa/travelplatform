## 3. 业务场景用例说明

### UC01 用户注册登录与退出

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 游客通过注册成为普通用户，普通用户或管理员通过账号密码登录系统，系统签发登录凭证；用户退出后系统清除登录状态。 |
| 参与者 | 游客、普通用户、管理员、系统 |
| 触发条件 | 用户进入普通登录注册页面或后台登录页面，并提交注册、登录或退出操作。 |
| 前置条件 | 注册时用户名未被占用；登录时账号存在、密码正确且账号状态正常；退出时用户已登录。 |
| 主成功流程 | 1. 用户打开登录或注册页面。2. 用户填写账号、密码等信息并提交。3. 系统校验输入格式和账号状态。4. 注册时系统创建用户账号；登录时系统校验密码。5. 系统返回 token 和用户信息。6. 前端保存登录状态并跳转到目标页面。7. 用户点击退出登录，系统清除登录状态。 |
| 备选或异常流程 | 1. 用户名已存在时，系统提示用户名不可用。2. 密码错误时，系统拒绝登录并提示错误。3. 账号被禁用时，系统拒绝登录。4. token 失效时，系统要求用户重新登录。 |
| 可验证结果 | 注册成功后可使用新账号登录；登录成功后可进入个人中心或后台；退出后访问受保护页面会跳转登录页。 |

### UC02 个人资料与常用联系人管理

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 普通用户在个人中心查看并修改个人资料，维护常用出行人信息，以便后续下单时快速选择联系人。 |
| 参与者 | 普通用户、系统 |
| 触发条件 | 普通用户进入个人中心并提交资料修改、联系人新增、联系人修改或联系人删除操作。 |
| 前置条件 | 用户已登录；待修改或删除的联系人属于当前用户。 |
| 主成功流程 | 1. 用户进入个人中心。2. 系统加载当前用户资料和联系人列表。3. 用户修改昵称、手机号等资料并保存。4. 用户新增、修改或删除常用联系人。5. 系统校验输入格式和数据归属。6. 系统保存变更。7. 前端刷新并展示最新资料和联系人列表。 |
| 备选或异常流程 | 1. 用户未登录时，系统跳转登录页。2. 手机号格式错误时，系统提示修改。3. 联系人不存在或不属于当前用户时，系统拒绝操作。4. 删除默认联系人后，系统按规则更新默认状态或提示用户重新设置。 |
| 可验证结果 | 个人资料更新成功；联系人可新增、修改、删除；下单页面可使用维护后的联系人信息。 |

### UC03 机票查询、详情查看与下单

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 普通用户查询航班、查看航班详情，填写乘机人信息并提交订单，系统校验库存后生成机票订单。 |
| 参与者 | 普通用户、系统 |
| 触发条件 | 用户从首页或导航栏进入机票预订模块，并选择某个航班下单。 |
| 前置条件 | 用户已登录；航班存在且处于可预订状态；航班库存充足；乘机人信息合法。 |
| 主成功流程 | 1. 用户输入出发地、目的地等查询条件。2. 系统返回航班列表。3. 用户查看航班详情。4. 用户进入下单页并填写乘机人信息。5. 用户提交订单。6. 系统校验航班库存和订单信息。7. 系统扣减库存并生成订单。8. 前端展示订单详情或下单成功结果。 |
| 备选或异常流程 | 1. 用户未登录时，系统跳转登录页。2. 航班不存在或已下架时，系统提示航班不可预订。3. 库存不足时，系统提示余票不足。4. 乘机人信息不合法时，系统提示用户修改后再提交。 |
| 可验证结果 | 订单中心出现新机票订单；订单详情显示航班和乘机人信息；航班库存减少。 |

### UC10 AI 或本地规则生成行程并保存

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 普通用户输入目的地、天数、出发日期和旅行偏好，系统基于 AI 或本地规则生成行程预览，用户确认后保存为正式行程。 |
| 参与者 | 普通用户、系统 |
| 触发条件 | 用户在行程规划模块点击 AI 生成行程入口并提交生成请求。 |
| 前置条件 | 用户已登录；系统存在可用于推荐的景点基础数据；用户输入的目的地、天数和日期合法。 |
| 主成功流程 | 1. 用户输入目的地、停留天数、出发日期和旅游偏好。2. 用户提交生成请求。3. 系统查询本地景点库。4. 系统调用 AI 生成行程，或使用本地规则生成行程。5. 系统返回按天拆分的行程预览。6. 用户确认保存。7. 系统写入行程计划和每日行程项。8. 前端展示保存后的行程详情。 |
| 备选或异常流程 | 1. AI 未配置或调用失败时，系统自动回退为本地规则生成。2. 目的地没有候选景点时，系统提示无法生成。3. 天数或日期不合法时，系统提示用户修改。4. 保存失败时，系统提示用户稍后重试。 |
| 可验证结果 | 系统返回行程预览；预览中区分 AI 增强或本地生成；保存后行程列表出现新计划。 |

| 前置条件 | 查看价格对比时商品存在；创建价格提醒时用户已登录且目标价格合法。 |
| 主成功流程 | 1. 用户进入商品详情页。2. 系统展示当前价格、优惠和价格对比信息。3. 用户输入目标价格并创建提醒。4. 系统保存价格提醒。5. 用户进入个人中心查看提醒列表。6. 用户可删除不再需要的价格提醒。 |
| 备选或异常流程 | 1. 商品不存在时，系统提示商品不存在。2. 用户未登录时创建提醒，系统跳转登录页。3. 目标价格为空、为负数或格式错误时，系统提示用户修改。4. 删除不存在或不属于当前用户的提醒时，系统拒绝操作。 |
| 可验证结果 | 商品详情页展示价格对比；价格提醒创建成功；个人中心可查看和删除该提醒。 |

### UC13 管理员商品与图片管理

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 管理员在后台维护航班、车次、酒店、房型、旅游产品等商品数据，并上传商品封面图或详情图。 |
| 参与者 | 管理员、系统 |
| 触发条件 | 管理员进入后台商品管理页面，并执行新增、修改、删除或上传图片操作。 |
| 前置条件 | 管理员已登录并拥有管理员角色；提交的商品字段、价格、库存和图片符合校验规则。 |
| 主成功流程 | 1. 管理员登录后台。2. 管理员进入商品管理页面。3. 系统展示商品列表。4. 管理员新增或修改商品信息。5. 管理员上传封面图或详情图。6. 系统保存商品数据和图片地址。7. 前台商品列表和详情页展示最新数据。 |

### UC14 管理员用户、订单、内容管理

| 项目 | 内容 |
| --- | --- |
| 用例说明 | 管理员在后台查看平台数据，管理用户状态和角色，管理订单状态，删除违规分享或评价内容。 |
| 参与者 | 管理员、系统 |
| 触发条件 | 管理员进入后台首页、用户管理、订单管理、分享管理或评价管理页面。 |
| 前置条件 | 管理员已登录并拥有管理员角色；被管理的用户、订单、分享或评价存在。 |
| 主成功流程 | 1. 管理员登录后台。2. 管理员查看后台统计数据。3. 管理员进入用户管理并修改用户状态或角色。4. 管理员进入订单管理并查看订单详情、修改订单状态或取消订单。5. 管理员进入内容管理并删除违规分享或评价。6. 系统保存管理操作并刷新后台页面。 |

| 可验证结果 | 后台统计数据可查看；用户状态或角色修改生效；订单状态更新生效；违规分享或评价被删除。 |
