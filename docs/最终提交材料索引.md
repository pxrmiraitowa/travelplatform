## 4. 最终提交前必须人工确认

1. 全组确认至少 3 个重点讲解用例，并在用例清单和 PPT 中使用一致编号。
2. 在 GitHub Actions 下载最终成功运行和至少一次失败诊断的原始报告，避免 30 天保留期过后丢失。
3. 由真实成员填写项目管理地址、站会、截图、权重和确认记录，不使用自动生成内容代替。
4. 检查仓库、压缩包和 PPT 中没有密码、Token、数据库真实口令或第三方 API Key。
5. 在另一台机器按 README 完成一次启动、健康检查、重点用例和两项云原生实验的抽查。
