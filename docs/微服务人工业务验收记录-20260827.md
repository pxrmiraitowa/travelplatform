## 6. 本次修复

| 问题 | 修复方式 |
| --- | --- |
| 订单评价提交成功后，订单详情仍显示“当前订单暂未评价” | 订单详情页加载已完成订单时补充调用 `/api/orders/{id}/review`，并合并 `reviewInfo` 与 `reviewed` 状态 |
| 订单列表中已评价订单仍显示“未评价” | 订单列表对已完成订单补充查询评价状态，前端展示与内容服务评价结果保持一致 |
| 后台首页提示“内容管理暂未启用” | 更新 dashboard 模块说明，使其匹配当前已迁移的分享/评价管理能力 |
| 酒店和旅游详情图片加载失败时出现英文 `FAILED` | 增加中文图片失败占位，改善演示观感 |

## 7. 剩余观察项

当前前端主流程和后台主页面已经可演示。后续可以继续优化后台订单、分享、评价列表中的用户展示，目前部分页面仍以 `用户#id` 展示用户信息；这不影响主流程可用性，但最终演示材料中如果追求观感，可以再补充后台侧用户基础信息聚合展示。

订单状态中的“模拟支付”和“完成订单”能力已经在 gateway 后端接口中可用，但前端订单详情页目前没有直接提供“模拟支付”按钮。本次验收通过接口完成状态流转，后续可以考虑把该按钮补回前端，便于老师或同学直接通过页面完成全流程演示。
