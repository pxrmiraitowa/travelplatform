## 真实服务联调

联调时同时启动 user-service、product-service 和 order-service，并使用独立的
`travel_user`、`travel_product`、`travel_order` 数据库。

| 场景 | 结果 |
| --- | --- |
| FLIGHT 创建 → 支付 → 完成 | 10 → 20 → 30，通过 |
| TRAIN 创建 → 取消 | 10 → 40，通过 |
| HOTEL 创建 → 取消 | 10 → 40，通过 |
| TOUR 创建 → 取消 | 10 → 40，通过 |
| FLIGHT 创建 → 支付 → 退款 | 10 → 20 → 50，通过 |
| 重复退款 | 返回 400 业务错误 |
| 已完成订单取消 | 返回 400 业务错误 |
| 未登录访问订单 | 返回 401 |
| 跨用户读取订单 | 返回 403 |
| 完成订单评价上下文 | `completed=true`，可评价列表可查询 |
| 普通用户访问后台用户接口 | 返回 403 |
| 管理员查询用户与角色 | 返回 200 |
| 管理员禁用自己 | 返回 400 |
| 管理员移除自己的管理员角色 | 返回 400 |
| 常用出行人创建、列表、更新、删除 | 全流程通过，删除后列表为空 |
