# AGENTS.md

## Project
This is a course project: a comprehensive travel platform.

## Tech stack
Backend: Spring Boot 3, Spring Security, MyBatis-Plus, MySQL, JWT
Frontend: Vue 3, Vite, Vue Router, Pinia, Element Plus, Axios

## Goals
Focus on complete business flow, stable demo, clear modular structure.
Do not introduce real payment or third-party live APIs.

## Conventions
- Reuse existing code first
- Keep controller/service/mapper/entity/dto/vo layering clear
- Use unified Result response format
- Do not modify unrelated modules
- Add clear comments for non-obvious business logic

## Done criteria
- Feature works end-to-end
- Frontend and backend can be run locally
- No breaking changes to existing modules
